# TBOMT
The Beginning Of Modern Times game.

## PL
Witaj w TBOMT, to piękna społeczność, która dalej się rozwija. TBOMT jest rozbudowaną fabularnie grą komputerową i jest w fazie rozwoju. Jeśli chcesz pobrać grę, pobierz plik program.py, on doinstalowuje wszystkie potrzebne pliki, aby gra mogła działać.

Uwaga! Gra jest udostępniana na licencji Creative Commons: CC BY-NC-SA 4.0, co uprawnia cię do rozpowszechniania (głównie po prostu po to aby umożliwić więcej języków tej gry) ale tylko pod warunkiem nie rozpowszechniania komercyjnego oraz podania źródła (którym jest gra TBOMT) z naszą stroną internetową tbomt.7m.pl, można też tylko podać źródło otwartego kodu na Githubie.
